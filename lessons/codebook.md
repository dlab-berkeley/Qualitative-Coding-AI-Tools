# Bracero Oral History Codebook

This codebook is for the workshop exercises in **Qualitative Coding with AI Tools**.

You will use this codebook to code interview responses both by hand and by using AI tools. Codes are divided into two **Tiers**: Tier 1, which are factual codes, and Tier 2, which are intepretive codes.

## Applying codes from the codebook
When you hand code, you will be provided a Google Doc in which you will carry out your coding. For each passage, record the following:

* **Code:** [YOUR CODE HERE]
* **Evidence:** [EVIDENCE SPAN FROM PASSAGE]
* **Why:** [EXPLANATION IN YOUR OWN WORDS]

2. **Multiple codes can apply to an evidence span.** You can feel free to assign multiple codes to the same span of text.

3. **You don't have to use every code.**  Don't try and "force" a code into a part of the text if you don't think it fits well.

4. **Disagreement is not a bad thing.**  If you find that you disagree with the AI or another human on what code to assign, it means there is an opportunity to improve the definition of the code or how it is applied to the text.

# Tier 1: Factual codes

A Tier 1 code asks a factual question, namely: "What is explicitly being described here?"

These codes still require judgment, and annotators might still disagree on whether a code applies or not. But often, the evidence is usually easier identify directly in the passage.

## `T1-CROP`: Crop or agricultural product

**Use this code when:** The passage names a specific crop, harvest, or agricultural product. 

Examples might include:
- cotton,
- onions,
- corn,
- cherries,
- or another named product.

### Example: **bha_1561_002**

> "we used to come home from school... and then you go out and work in the fields... to go out there and pick onions."

The word **“onions”** is enough to support `T1-CROP`.


## `T1-SITE`: Physical setting

**Use this code when:** The passage describes a physical place where people lived, worked, received services, or moved through the program.

Examples might include:

- housing,
- a labor camp,
- barracks,
- a clinic,
- a farm,
- a reception center,
- or the physical layout or material condition of a site.

In particular, look for concrete details, like size, construction, rooms, flooring, beds, or number of buildings.

### Example: **bha_1574_001**

> "It was pretty good size barn... eighty feet wide by about a hundred and twenty feet long. They were bunked at what they would call the hayloft."

The passage gives a concrete description of the place where workers were housed.

## `T1-CONTRACT`: Formal terms or obligations

**Use this code when:** The passage refers to the formal terms that governed a worker's participation in the Bracero Program.

Examples might include:

- promised wages,
- insurance requirements,
- deductions established by the agreement,
- legal status,
- formal employment conditions, 
- or paperwork setting out rights or obligations.

### Example: **bha_1573_001**

> "all the Braceros had to have five hundred dollar non-occupational insurance, five thousand dollar occupational insurance, and thirteen hundred dollars life insurance policy."

This describes a formal insurance requirement attached to the program.

## `T1-PROC`: Procedure or system in operation

**Use this code when:** The passage explains how something was done.

Examples might include:

- how workers were recruited,
- how pay was recorded,
- how workers were identified,
- how a clinic operated,
- how transportation was arranged,
- how discipline worked,
- or how an institution handled a recurring task.

This is a broad code. The main thing you should ask when applying this code is whether the narrator is describing a process, routine, or system rather than a one-time event.

### Example: **bha_1593_024**

> "we had their name up there, and the Hispanics, we had their numbers."

This describes a recordkeeping procedure that treated groups differently.


## `T1-WAGE`: Pay, rate, or deduction

**Use this code when:** The passage states or clearly describes pay or wages.

Examples might include:

- a wage,
- an hourly or piece rate,
- a paycheck amount,
- a deduction,
- a payment mechanism, 
- or another specific way workers were paid.

### Example: **bha_1561_001**

> "the paycheck was probably $2.00."

This is a direct statement about the amount left in a paycheck.

# Tier 2: Interpretive and affective codes

Tier 2 focuses on a more subject question, namely, "How is the experience being framed, judged, or felt?"

These codes require more interpretation than Tier 1. Reasonable readers may disagree on whether to assign a code or not.

## `T2-AMBIV`: Ambivalence

**Use this code when:** The narrator holds two different evaluations or feelings at the same time without fully resolving the tension between them.

Examples might include:

- gratitude alongside resentment,
- warmth alongside criticism,
- pride alongside pain,
- humor around something uncomfortable, or
- recognition of both benefit and harm.

### Example: **bha_1588_003**

> "I know the merchants made... a lot of money from them, but I do remember some of them not being very nice to them."

The narrator recognizes economic benefit and mistreatment in the same reflection.

## `T2-DIGNITY`: Dignity, agency, or capability

**Use this code when:** The passage presents a bracero as a person with agency, skill, knowledge, aspiration, judgment, or worth, rather than only a unit of labor. The narrator does not have to be a bracero for this code to apply.

Evidence for this code could look like language showing workers:

- making choices,
- learning,
- teaching,
- improving their circumstances,
- exercising skill,
- planning for the future, or
- being treated as people whose knowledge and aspirations matter.

### Example: **bha_1582_002**

The narrator describes workers learning well-drilling techniques so they could

> "take them back to their villages"

and describes them as

> "looking for new ways to improve themselves."

The workers are represented as active learners with plans beyond the immediate job.

## `T2-NEGCOMP`: Negotiating compliance and power

**Use this code when:** The passage shows how power is exercised, accepted, resisted, negotiated, or avoided.

Examples may involve:

- pressure to comply,
- unequal bargaining power,
- institutional authority,
- workers resisting or negotiating a demand,
- someone shifting responsibility to another institution, or
- a narrator describing an exercise of power without questioning it.

This code is deliberately interested in who gets to decide, who has room to refuse, and who is held responsible.

### Example: **bha_1573_004**

After braceros were deputized to fight an oil-well fire and workers were injured, the company response is described as:

> "we are not responsible because the sheriff deputized them."

The passage raises questions about authority, responsibility, and who bears the consequences of an institutional decision.

## `T2-RETRO`: Retrospective judgment

**Use this code when:** The narrator steps back and gives an overall judgment about the Bracero Program or a major part of the experience. The judgment may be positive, negative, or mixed.

The key detail to identify is whether the narrator is offering something like a **verdict**, rather than describing an event.


### Examples: **bha_1573_005** and **bha_1561_005**

> "it helped the people in the United States and it helped the Mexican people."

This is an overall positive assessment of the program.

> "pretty much legalized slavery is what happened."

This is an overall negative assessment.

The two passages reach very different conclusions about the same historical program. The code captures the act of retrospective judgment.


## `T2-HARDSHIP`: Hardship

We are not giving this code a complete definition yet. As you work through the first set of passages, notice what you think should count as hardship.

You might find yourself asking:

- Does low pay automatically count?
- Does physical danger count even if the narrator describes it matter-of-factly?
- Does humiliation or shame count?
- Does hardship have to be explicitly named by the narrator?
- Should we code a difficult material condition, a feeling about that condition, or both?

For now, use your best judgment to assign this code. Be sure to always provide an evidence span when you do.

We will return to this definition later in the workshop.


# Common overlapping codes

You will often find that some codes will overlap. Some common combinations might include:

* `T1-CONTRACT` and `T1-WAGE`: Use both when a passage discusses a pay rate or deduction as part of a formal employment arrangement.
* `T1-PROC` and another Tier 1 code: A passage may describe how something worked and what it involved. For example, a passage about how deductions were processed might receive both `T1-PROC` and `T1-WAGE`.
* Tier 1 and Tier 2 codes: A passage can describe a concrete fact and also carry an evaluative or emotional meaning. For example:
   - a dangerous work procedure may also suggest hardship;
   - a wage deduction may also become part of a retrospective judgment;
   - a workplace routine may also reveal unequal power.
