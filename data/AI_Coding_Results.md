# Precomputed AI Coding Results

This file contains the precomputed AI coding run used in **Qualitative Coding with AI Tools**.

These results are **not an answer key**.

They are material to inspect.

For each passage, the model was asked to:

1. assign any Tier 1 and Tier 2 codes that applied;
2. support each code with an exact quotation from the passage; and
3. note any ambiguity in its own coding.

As you read, keep the [32-passage source corpus](Source_Passages.md) open beside this file.

> **Your job is to audit the output, not to agree with it.**

For any coding decision, ask:

- Is the quoted evidence actually in the source passage?
- Is it quoted accurately?
- Does the evidence support the code?
- Is another code more plausible?
- Does the codebook itself leave too much room for interpretation?

> **No quote, no code.**
